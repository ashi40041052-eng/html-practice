# HTML Practice

添付画像を組み立てる形式のLPです。  
以下のファイル名で `assets/` に画像を配置すると、デザインがそのまま表示されます。

## 必要画像
- `assets/hero.jpg`
- `assets/about.jpg`
- `assets/conditions.jpg`
- `assets/flow.jpg`
- `assets/organizer.jpg`
- `assets/notes.jpg`
- `assets/final-cta.jpg`

## ローカル確認
```bash
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開いてください。

## GitHub Pages
- `main` ブランチ / `(root)` で公開設定
- 画像も必ず同じブランチに commit してください
